STUDIO M EXCLUSIVE - SINGLE PAGE WEBSITE

Fajlovi:
- index.html
- style.css
- script.js
- assets/ (logo i slike)

Kako pokrenuti lokalno:
1. Otvori index.html u browseru.
2. Za najbolji rezultat možeš koristiti VS Code + Live Server.

Kako deployati na GitHub Pages:
1. Kreiraj novi GitHub repository (npr. studio-m-exclusive).
2. Uploaduj kompletan sadržaj ovog foldera.
3. Settings > Pages > Deploy from a branch.
4. Izaberi main i /(root), pa Save.

Za kasnije promijeniti:
- Telefon: pretraži "Telefon: uskoro" u index.html.
- Radno vrijeme: pretraži "Radno vrijeme: uskoro".
- Instagram: već je postavljen na @studio_m_exclusive.
- Slike: zamijeni fajlove u assets/ folderu istim imenima.
